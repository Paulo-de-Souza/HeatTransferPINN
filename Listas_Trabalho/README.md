## Recomendações

Mesmo antes das aulas específicas sobre PINNs, os alunos já podem iniciar o trabalho:

1. Ler atentamente o PDF do projeto escolhido;
2. Escolher uma das opções de problema;
3. Ler os artigos de referência indicados;
4. Consultar os códigos disponibilizados pelos artigos e as ferramentas utilizadas, como o DeepXDE;
5. Identificar a equação, as condições de contorno/iniciais, os parâmetros e os dados necessários para o problema.

Não é necessário aguardar as aulas de PINNs para começar a leitura dos artigos e a familiarização com o problema escolhido.
